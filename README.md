# Administration Table

A Django-based web application for managing and organizing administrative information through a structured table interface.

## Overview

Administration Table is a web-based project developed using Python and Django. It provides a structured approach to organizing and managing administrative records.

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite3

## Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/sorforaj99tech/administration_table.git
```

2. Navigate to the project directory:

```bash
cd administration_table
```

3. Create a virtual environment:

```bash
python -m venv env
```

4. Activate the virtual environment:

```bash
# Windows
env\Scripts\activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```

6. Apply database migrations:

```bash
python manage.py migrate
```

7. Run the development server:

```bash
python manage.py runserver
```

8. Open in your browser:

```text
http://127.0.0.1:8000/
```
